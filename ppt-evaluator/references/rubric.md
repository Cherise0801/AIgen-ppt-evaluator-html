# PPT 测评评分细则（Rubric）

本文件是 PPT 测评的权威评分标准。执行任何评分任务前必须完整阅读本文件。

## 总览

| 维度 | 默认权重 | 计分方式 | 评估层面 |
|------|----------|----------|----------|
| 1. 内容质量 | 20% | 1-10 分 | 全文 |
| 2. 结构逻辑 | 16% | 1-10 分 | 全文 |
| 3. 视觉设计 | 20% | 1-10 分 | 全文 + 逐页 |
| 4. 表达传达 | 16% | 1-10 分 | 全文 + 逐页 |
| 5. 技术规范 | 8% | 1-10 分 | 全文 |
| 6. 版面合规 | 10% | 扣分制 | 逐页 |
| 7. 版式多样性 | 10% | 1-10 分 | 全文 |

**加权总分公式**：
```
总分 = Σ(维度得分 × 维度权重)    // 满分 10 分
百分制 = 总分 / 10 × 100
```

## 评分通用原则

- 每个维度独立评分，不受其他维度影响。
- 评分必须对照下方锚点，给出"为什么是这个分数"的具体依据。
- 依据必须引用 PPT 中的具体页面编号和元素（如"第 3 页标题栏""第 5 页数据表格"）。
- 分数拉开差距：宁可偏低也不虚高。合格线 6 分，良好 7.5 分，优秀 8.5 分以上。

## 维度 1：内容质量（20%）

评估信息的准确性、密度、深度和价值。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 信息准确、密度高、有洞察，每页都有增量价值；数据有来源、观点有支撑 |
| 7-8 | 信息基本准确、密度适中；大部分页面有价值，个别页面信息冗余或空洞 |
| 5-6 | 信息准确但密度低；部分页面信息空洞、套话多、缺少实质内容 |
| 3-4 | 信息密度很低或存在明显错误；大量页面是填充性内容 |
| 1-2 | 信息严重错误、逻辑混乱，或几乎无实质内容 |

**评分要点**：
- 每页是否提供了观众真正需要的信息？
- 数据/观点是否有来源和支撑？
- 是否存在"车轱辘话"（同一观点反复说）？
- 是否存在事实性错误或过时信息？

---

## 维度 2：结构逻辑（16%）

评估叙事线、页间衔接和整体论证结构。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 叙事线清晰，页间衔接自然，符合金字塔结构（结论先行→论据支撑→行动建议） |
| 7-8 | 有清晰主线，但个别页面逻辑跳跃或顺序可优化 |
| 5-6 | 有基本结构但不够严密；部分页面之间的逻辑关系不清晰 |
| 3-4 | 结构松散，页间缺乏衔接；观众难以跟上思路 |
| 1-2 | 无逻辑结构，页面随机堆叠 |

**评分要点**：
- 是否有明确的"总-分-总"或"问题-分析-方案"结构？
- 每页之间是否有逻辑递进或并列关系？
- 目录/章节划分是否合理？
- 结论是否有前面的论据支撑？

---

## 维度 3：视觉设计（20%）

评估配色、留白、可读性、视觉层次和整体美感。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 配色协调统一、留白得当、视觉层次清晰；有设计感但不喧宾夺主 |
| 7-8 | 配色基本协调、可读性良好；个别页面视觉层次可优化 |
| 5-6 | 配色或留白有明显问题；视觉层次不清晰，重点不突出 |
| 3-4 | 配色混乱、留白不足或过度；视觉层次差，观众难以聚焦 |
| 1-2 | 视觉上令人不适，严重影响信息获取 |

**评分要点**：
- 配色是否协调统一（主色不超过 3 种）？
- 留白是否合理（不拥挤也不过于空旷）？
- 视觉层次是否清晰（标题→要点→正文有明确层级）？
- 图文比例是否得当？
- 是否有不必要的装饰元素干扰阅读？

---

## 维度 4：表达传达（16%）

评估标题力、要点精炼程度和说服力。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 标题即观点、要点精炼有力、一句话能抓住注意力；说服力强 |
| 7-8 | 标题基本达意、要点清晰；个别页面表达可更精炼 |
| 5-6 | 标题是"名词短语"而非"观点句"；要点冗长或模糊 |
| 3-4 | 标题空洞（如"关于 XXX"）；要点堆砌，缺乏提炼 |
| 1-2 | 表达混乱，观众无法理解核心信息 |

**评分要点**：
- 每页标题是否直接传达观点（而非仅标注主题）？
- 要点是否精炼（每条不超过 2 行）？
- 是否存在"标题说一件事，内容说另一件事"？
- 整体是否有说服力（数据+逻辑+情感）？

---

## 维度 5：技术规范（8%）

评估 HTML 结构、响应式、渲染正确性。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | HTML 结构语义化、无冗余代码、响应式良好、无渲染错误 |
| 7-8 | HTML 结构基本规范，个别地方可优化；基本无渲染问题 |
| 5-6 | HTML 结构有冗余或不规范；存在轻微渲染问题 |
| 3-4 | HTML 结构混乱；存在明显渲染问题（错位、闪烁） |
| 1-2 | HTML 严重不规范，无法正常渲染 |

**评分要点**：
- HTML 标签是否语义化（h1/h2/p/section 等）？
- 是否有内联样式与外部样式混用导致的混乱？
- 是否存在无效标签或未闭合标签？
- 不同屏幕尺寸下是否能正常显示？
- 是否有 CSS 冲突导致的样式异常？

---

## 维度 6：版面合规（10%）— 扣分制

评估是否存在**爆版**（内容溢出页面边界）和**叠版**（元素重叠遮挡）问题。

**计分方式**：基础满分 10 分，每发现一处爆版或叠版问题扣 2 分，最低 0 分。

| 问题类型 | 定义 | 扣分 |
|----------|------|------|
| 爆版 | 文本、图片、图表等元素超出页面容器边界 | 每处 -2 分 |
| 叠版 | 两个或多个元素重叠，导致内容被遮挡或难以阅读 | 每处 -2 分 |

**评分流程**：
1. 逐页检查每页的所有元素
2. 标记所有爆版问题（元素超出边界）和叠版问题（元素重叠遮挡）
3. 统计问题总数，计算扣分
4. 得分 = max(10 - 问题数 × 2, 0)

**常见爆版场景**：
- 文本超出文本框或页面边界
- 图片/图表溢出容器
- 表格列宽不足导致内容截断
- 页码/脚注超出页边距

**常见叠版场景**：
- 标题与正文重叠
- 图片遮挡文字
- 多个元素 z-index 冲突导致叠压
- 图表标签与数据点重叠

---

## 维度 7：版式多样性（10%）

评估全文版式的丰富度、差异化和内容匹配度。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 版式丰富多样且与内容高度匹配；不同页面类型（标题/内容/对比/数据/结尾）采用差异化布局 |
| 7-8 | 版式有基本变化，但部分页面类型重复；版式与内容基本匹配 |
| 5-6 | 版式单一，大部分页面布局雷同；版式与内容类型有脱节 |
| 3-4 | 版式高度单一，几乎每页同一布局；版式与内容明显不匹配 |
| 1-2 | 全文一种版式，完全无变化 |

**评分要点**：
- 全文使用了多少种不同的版式？
- 版式是否与该页内容类型匹配（对比页用左右对比、数据页用图表、列表页用条目排列）？
- 是否存在"每页都是标题+正文"的单调感？
- 是否有页面因为版式单一而显得拥挤或空洞？

**常见版式类型参考**：
- 标题页（大标题+副标题）
- 内容页（标题+正文/要点）
- 对比页（左右/上下对比布局）
- 数据页（图表+简要说明）
- 列表页（多条目排列）
- 图文页（图片+文字说明）
- 结尾页（总结+行动建议/联系方式）
