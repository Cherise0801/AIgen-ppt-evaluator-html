# PPT 测评评分细则（Rubric）

本文件是 PPT 测评的权威评分标准。执行任何评分任务前必须完整阅读本文件。

## 总览

PPT 测评采用 **6 维评分模型**（已删除"技术规范"维度，因为该维度评的是"代码质量"而非"演示效果"，对最终观众体验影响有限，且严重的实现问题会通过视觉/版面合规维度间接体现）。

| 维度 | 权重 | 计分方式 | 评估层面 |
|------|------|----------|----------|
| 1. 内容质量 | 20% | 1-10 分 | 全文 |
| 2. 结构逻辑 | 16% | 1-10 分 | 全文 |
| 3. 视觉设计 | 24% | 1-10 分 | 全文 + 逐页 |
| 4. 表达传达 | 16% | 1-10 分 | 全文 + 逐页 |
| 5. 版面合规 | 14% | 扣分制 | 逐页 |
| 6. 版式多样性 | 10% | 1-10 分 | 全文 |

**加权总分公式**：
```
总分 = Σ(维度得分 × 维度权重)    // 满分 10 分
百分制 = 总分 / 10 × 100
```

## 评分通用原则

- 每个维度独立评分，不受其他维度影响。
- 评分必须对照下方锚点，给出"为什么是这个分数"的具体依据。
- 依据必须引用 PPT 中的具体页面编号和元素（如"第 3 页标题栏""第 5 页数据表格"）。
- 分数拉开差距：宁可偏低也不虚高。合格线 6 分，良好 7.5 分，优秀 8.5 分以上。
- **版面合规维度从严**：宁可多扣分，不要漏判。同一页多个独立元素叠版，应分别计分（不要因为"都在同一页"就合并为 1 处）。

## 维度 1：内容质量（20%）

评估信息的准确性、密度、深度和价值。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 信息准确、密度高、有洞察，每页都有增量价值；数据有来源、观点有支撑 |
| 7-8 | 信息基本准确、密度适中；大部分页面有价值，个别页面信息冗余或空洞 |
| 5-6 | 信息准确但密度低；部分页面信息空洞、套话多、缺少实质内容 |
| 3-4 | 信息密度很低或存在明显错误；大量页面是填充性内容 |
| 1-2 | 信息严重错误、逻辑混乱，或几乎无实质内容 |

**评分要点**：
- 每页是否提供了观众真正需要的信息？
- 数据/观点是否有来源和支撑？
- 是否存在"车轱辘话"（同一观点反复说）？
- 是否存在事实性错误或过时信息？

---

## 维度 2：结构逻辑（16%）

评估叙事线、页间衔接和整体论证结构。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 叙事线清晰，页间衔接自然，符合金字塔结构（结论先行→论据支撑→行动建议） |
| 7-8 | 有清晰主线，但个别页面逻辑跳跃或顺序可优化 |
| 5-6 | 有基本结构但不够严密；部分页面之间的逻辑关系不清晰 |
| 3-4 | 结构松散，页间缺乏衔接；观众难以跟上思路 |
| 1-2 | 无逻辑结构，页面随机堆叠 |

**评分要点**：
- 是否有明确的"总-分-总"或"问题-分析-方案"结构？
- 每页之间是否有逻辑递进或并列关系？
- 目录/章节划分是否合理？
- 结论是否有前面的论据支撑？

---

## 维度 3：视觉设计（20%）

评估配色、留白、可读性、视觉层次和整体美感。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 配色协调统一、留白得当、视觉层次清晰；有设计感但不喧宾夺主 |
| 7-8 | 配色基本协调、可读性良好；个别页面视觉层次可优化 |
| 5-6 | 配色或留白有明显问题；视觉层次不清晰，重点不突出 |
| 3-4 | 配色混乱、留白不足或过度；视觉层次差，观众难以聚焦 |
| 1-2 | 视觉上令人不适，严重影响信息获取 |

**评分要点**：
- 配色是否协调统一（主色不超过 3 种）？
- 留白是否合理（不拥挤也不过于空旷）？
- 视觉层次是否清晰（标题→要点→正文有明确层级）？
- 图文比例是否得当？
- 是否有不必要的装饰元素干扰阅读？

---

## 维度 4：表达传达（16%）

评估标题力、要点精炼程度和说服力。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 标题即观点、要点精炼有力、一句话能抓住注意力；说服力强 |
| 7-8 | 标题基本达意、要点清晰；个别页面表达可更精炼 |
| 5-6 | 标题是"名词短语"而非"观点句"；要点冗长或模糊 |
| 3-4 | 标题空洞（如"关于 XXX"）；要点堆砌，缺乏提炼 |
| 1-2 | 表达混乱，观众无法理解核心信息 |

**评分要点**：
- 每页标题是否直接传达观点（而非仅标注主题）？
- 要点是否精炼（每条不超过 2 行）？
- 是否存在"标题说一件事，内容说另一件事"？
- 整体是否有说服力（数据+逻辑+情感）？

---

## 维度 5：技术规范（已删除）

**该维度已删除**。原评 HTML 标签语义、代码冗余、渲染稳定性等属于"代码质量"问题，不直接影响观众对演示的体验。
- 渲染稳定性差导致视觉变形 → 在"视觉设计"维度扣分
- CSS 实现问题导致元素位置错乱 → 在"版面合规"维度扣分

## 维度 6：版面合规（14%）— 扣分制

评估是否存在**爆版**（内容溢出页面边界）和**叠版**（元素重叠遮挡）问题。

**计分方式**：基础满分 10 分，每发现一处爆版或叠版问题扣分，最低 0 分。

### 扣分细则

| 问题类型 | 定义 | 严重度 | 扣分 |
|----------|------|--------|------|
| 爆版 | 文本、图片、图表等元素超出页面容器边界 | 轻微（边缘溢出 <20px） | -1 分 |
| 爆版 | 同上 | 严重（溢出 >20px 或被截断） | -2 分 |
| 叠版 | 两个或多个元素重叠，导致内容被遮挡或难以阅读 | 轻微（小范围 <50px²） | -1 分 |
| 叠版 | 同上 | 严重（大范围 / 文字成团 / 不可读） | -2 分 |
| 同页多处叠版 | 同一页内不同独立区块的叠版问题 | 应**分别计分**，不要合并为 1 处 | 每处 -1~-2 分 |

**计分流程**：
1. 逐页检查每页的所有元素
2. 标记所有爆版问题（元素超出边界）和叠版问题（元素重叠遮挡）
3. **关键**：同一页内如果有多组独立元素各自叠版，应按子元素分别计分
4. 得分 = max(10 - Σ扣分, 0)

**重要提示**：
- **静态 HTML 文本分析可能漏判**——CSS 在 flex / absolute / transform 等组合下渲染不稳定，**应优先以浏览器实际渲染为准**
- **不要把"设计上的重叠"误判为版式问题**——例如 Venn 图（两个圆设计来重叠）、网格线、装饰图案等属于设计语义，不扣分
- **真正该扣的是"文字/内容的叠版"**——即两个本应分离的文本/数据元素互相遮挡、不可读的情况

**常见爆版场景**：
- 文本超出文本框或页面边界
- 图片/图表溢出容器
- 表格列宽不足导致内容截断
- 页码/脚注超出页边距

**常见叠版场景**：
- 标题与正文重叠
- 图片遮挡文字
- 多个数据标签互相堆叠
- 卡片内的说明文字/数字与卡片标题重叠
- 多个 list item 的内联图标/标记互相挤压

## 维度 6：版式多样性（10%）

评估全文版式的丰富度、差异化和内容匹配度。

---

## 维度 7：版式多样性（10%）— 重命名提示

本节历史为"维度 7"，在 6 维模型下已重命名为"维度 6"（位于上方）。如需旧版请看 git 历史。

| 分数 | 锚点描述 |
|------|----------|
| 9-10 | 版式丰富多样且与内容高度匹配；不同页面类型（标题/内容/对比/数据/结尾）采用差异化布局 |
| 7-8 | 版式有基本变化，但部分页面类型重复；版式与内容基本匹配 |
| 5-6 | 版式单一，大部分页面布局雷同；版式与内容类型有脱节 |
| 3-4 | 版式高度单一，几乎每页同一布局；版式与内容明显不匹配 |
| 1-2 | 全文一种版式，完全无变化 |

**评分要点**：
- 全文使用了多少种不同的版式？
- 版式是否与该页内容类型匹配（对比页用左右对比、数据页用图表、列表页用条目排列）？
- 是否存在"每页都是标题+正文"的单调感？
- 是否有页面因为版式单一而显得拥挤或空洞？

**常见版式类型参考**：
- 标题页（大标题+副标题）
- 内容页（标题+正文/要点）
- 对比页（左右/上下对比布局）
- 数据页（图表+简要说明）
- 列表页（多条目排列）
- 图文页（图片+文字说明）
- 结尾页（总结+行动建议/联系方式）

## 评分自查清单

完成评分后，对照以下清单自检：

- [ ] 6 维总分 × 权重 = 加权总分，公式正确？
- [ ] 6 个维度权重之和 = 100%？
- [ ] 版面合规扣分时，同页多处叠版是否分别计分了？
- [ ] 扣分依据是否引用了具体页码和元素？
- [ ] 没有把"设计上的重叠"（Venn 图、网格线）误判为叠版问题？
- [ ] 评分前是否已用浏览器实际渲染过关键页（不只静态读 HTML）？
