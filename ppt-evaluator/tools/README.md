# tools/ - 本地校准工具

用于"人工盲测"和"AI vs 人工对比分析"的本地程序，不依赖任何外部服务。

## 工作流程

```
┌────────────────────────────────────────────────────────┐
│  1. 准备 cases                                         │
│     - 每个 case 一个子目录                             │
│     - 含 input.txt（输入描述）                          │
│     - 含 a.html（方案 A 生成结果）                      │
│     - 含 b.html（方案 B 生成结果）                      │
└────────────────────────────────────────────────────────┘
                          ↓
┌────────────────────────────────────────────────────────┐
│  2. 启动 server.py                                     │
│     python tools/server.py                             │
│     → 浏览器打开 http://127.0.0.1:5050                  │
│     → 两两对比界面，点击 A 或 B 完成盲测                │
│     → 结果自动存到 results/human_results.json           │
└────────────────────────────────────────────────────────┘
                          ↓
┌────────────────────────────────────────────────────────┐
│  3. 跑 AI 测评（用本 Skill）                            │
│     - 用 /ppt-blind 对每对 case 跑一遍                  │
│     - 把结果整理为 results/ai_results.json              │
│     - 格式见本 README 下文                              │
└────────────────────────────────────────────────────────┘
                          ↓
┌────────────────────────────────────────────────────────┐
│  4. 对比分析                                            │
│     python tools/analyze.py                            │
│     → 生成 report.md / report.html / summary.json       │
│     → 包含：一致率、分维度准确率、分歧 case 清单        │
└────────────────────────────────────────────────────────┘
```

## 安装

```bash
# 依赖：Python 3.8+ 和 Flask
pip install flask

# 启动服务
python tools/server.py
# → 浏览器访问 http://127.0.0.1:5050
```

可选参数：
- `--port 5050`：自定义端口
- `--cases ../cases`：自定义 cases 目录
- `--results ../results`：自定义结果目录

## 准备 cases

每个 case 是一个子目录：

```
cases/
├── case-001/
│   ├── input.txt    # 输入描述（给用户看的 prompt）
│   ├── a.html       # 方案 A 的生成结果
│   └── b.html       # 方案 B 的生成结果
├── case-002/
│   ├── input.txt
│   ├── a.html
│   └── b.html
└── ...
```

`a.html` 和 `b.html` 是**同一输入下两个不同来源的生成结果**（如：同一 prompt，模型 A 生成 vs 模型 B 生成，或人做 vs AI 生成）。盲测时**不告诉用户**哪份是哪个来源。

## 人工盲测界面

- 左 A 右 B 双栏布局，通过 iframe 渲染真实的 HTML PPT
- 键盘快捷键：`←` 选 A，`→` 选 B，`Space` 跳过
- 可选信心度（1-5），用于分析"人在不同信心度下 AI 一致率"
- 进度可视化（echarts 饼图）

## 对比分析输出

- `report.md`：Markdown 报告（GitHub 直接渲染）
- `report.html`：HTML 可视化报告（含 echarts 图表）
- `summary.json`：机器可读摘要

## 为什么需要这个工具

仅靠 AI 测评无法证明 Skill 的可信度。本工具用人工盲测作为 ground truth，反向验证 AI 测评的准确率：
- **总一致率**：AI 和人判断相同的比例
- **分维度准确率**：AI 在哪些维度上判断最准/最差
- **分歧 case 清单**：找出 AI 误判的 case，针对性优化

跑一批 case 就有了一批标注数据，越用 Skill 越准。
